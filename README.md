# Next.js API Template (JavaScript)

Complete API template using **folder-based route registration** with:

- Versioned API path (`/api/v1/...`)
- Dynamic route folder (`[paramsId]`)
- Global middleware for API version control
- Route layout wrapper (pre-handler system) for logs/error handling
- Alias imports (`@/`) to avoid relative paths like `../../`
- Full run scripts (`dev`, `build`, `start`) and log variants (`*:log`)

## Quick start

```bash
npm install
npm run dev
```

See: `docs/api-structure.md`
